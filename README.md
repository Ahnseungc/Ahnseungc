<details>
<summary><b>주요 성과 (펼치기)</b></summary>

### (주)골드앤컴퍼니
- Flutter WebView ↔ Next.js **브릿지** (인증·이벤트·라우팅 동기화), App Link / OneLink 딥링크
- 앱테크 참여율 **+50%**, 딥링크 전환 **+12%**, D+7 재방문 **+20%**
- 루프 미디어 **~20MB → ~0.7MB**, Lighthouse LCP/FCP **40~50 → 80~90**
- Toss Payments · FCM→OneSignal · **GitHub Actions + ECR** CI/CD (배포 **10분 → 5분**)

### (주)케어마인더
- RN → **WebView + Next.js** · 모노레포 · **CDS(Atomic Design)**
- QR 병상 오더: 주문 시작 완료율 **20% → 30%**, 만료 세션 차단 **~99%**
- 코드량 **~40% 감소**, UI 개발 속도 **+50%**, 저사양 태블릿 FPS 안정화

</details>
